# 实验复盘模板迭代记录

## 2026-04-07

### 三次修订
#### 修订原因
- 当前模板把“最低交付线”“空结果禁令”“专项链路必补”“固定全量表头”写得过重
- 实际使用中，AI 会优先补格式，导致结果层还没出全，就大量写“未成熟 / 无此口径”
- 这和当前需求冲突：先把能查到的结果层数据打出来

#### 本次修订内容
- 将主模板改为“出数第一，结果层第一”
- 把取数顺序从“硬阻塞”改为“推荐优先级”
- 把最低交付线收缩为：
  - 分流依据
  - 至少一张结果层表
  - 数据新鲜度说明
- 删除“核心表不允许留空单元格”的强制逻辑
- 删除“必须用标准状态词填满所有缺失字段”的强制逻辑
- 删除“任务链路 / 分享链路 / CAC / 显著性缺失会阻塞复盘”的逻辑
- 改为：
  - 先展示已拿到的数据
  - 缺失项统一放在“缺口与风险”
  - 表格字段按已取到的数据裁剪

#### 当前版本变化总结
- 模板从“格式完整优先”改成“结果层出数优先”
- 后续不应再为了凑表头，写大量“未成熟 / 无此口径”
- 任务类和分享类实验，也应先把主结果层打出来，再补专项链路

## 2026-04-07

### 四次修订
#### 修订原因
- 需要保证每次复盘都有一个固定的 `单杯实收` 字段，并统一“人均”口径为实际下单用户，避免使用入组人数导致混淆。

#### 本次修订内容
- 在主模板中规定结果表必须包含“单杯实收”，缺该数据时在“缺口与风险”说明。
- “人均”类公式全部改为以当期下单用户（购买用户）为分母，并在文本里明确该口径。

#### 当前版本变化总结
- 结果表里多了一个固定字段“单杯实收”。
- 所有“人均”指标围绕购买用户展开，口径一致。

### 二次修订原因
- 上一轮在线实验复盘虽然完成了飞书交付，但不少 sheet 仍出现“结果项缺失”
- 根因不是模板没表头，而是模板没有把“线上跑数优先”和“禁止空交付”写成硬约束
- 需要从“固定输出格式”升级到“固定交付门槛 + 固定取数顺序 + 固定缺口证据”

### 二次修订内容
- 重写主模板 `universal-experiment-review-prompt-通用实验复盘Prompt.md`
- 明确默认执行顺序为：
  - 先确认实验口径
  - 先线上跑数
  - 再判断结论
  - 最后再写飞书
- 新增“最低交付线”：
  - 分流依据
  - 按组累计结果
  - 按组日度结果
  - 数据新鲜度说明
  - 显著性表或显著性缺失说明
  - 任务 / 分享专项链路表
- 新增“空结果禁令”：
  - 核心结果表、显著性表、日度结果表不允许留空单元格
  - 必须填数值或标准状态词
- 新增“可推导指标先推导”规则：
  - 人均实收
  - 单杯实收
  - 人均杯量
  - 下单率
  - 访购率
- 新增“数据取数状态”模块：
  - 数据项
  - 取数方式 / 来源
  - 最大日期
  - 状态
  - 备注
- 明确本地月报 / 周报 / 旧复盘只用于校验口径和补业务解释，不能直接替代本次线上结果层数据

### 二次修订变化总结
- 模板不再只是“写得规范”
- 而是升级为“取数流程 + 交付门槛 + 缺口证据”三位一体模板
- 后续再做飞书实验复盘时，应该先补齐线上底表，再进入写作阶段
- 目标是杜绝“表格结构完整，但结果仍大量缺失”的交付问题
