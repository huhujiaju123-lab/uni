# 新人循环补券方案

## 文档信息
- 本地归档时间：2026-03-30
- 飞书文档链接：https://lkusco.feishu.cn/docx/Wo1CdtaE1o2MuRxHX7JcieT5nVh
- 适用场景：美国瑞幸新客塞券策略
- 2026-04-02 对齐说明：当前执行口径以飞书 wiki《美国新客循环策略》为准，覆盖 `0→1单 / 1→2单 / 2→3单`

## 一、背景
当前新人券包为：`1.99（7天有效）`、`2.99（次日-15天有效）`、`3.99（15天有效）`、`5折（15天有效）`。

从实际使用情况看，大部分新客在前15天仅使用首张 `1.99`，后续 `2.99 / 3.99 / 5折` 未被有效承接即过期，导致用户在第二单、第三单阶段缺少价格梯度承接，影响后续转化与留存。

因此，需要增加一套循环补券策略，在不造成券冗余的前提下，对处于新人承接阶段但当前无有效承接券的用户进行补券，提升二单、三单承接效率，并带动留存提升。

## 二、目标
本次策略目标是提升首单用户后续转化，重点改善留存表现。

业务评估口径可看自然月次月留存；策略执行口径采用滚动窗口，统一按 `首单后T+60` 执行，以保证策略稳定性并覆盖自然月次月留存影响周期。

本次策略遵循以下原则：
- 仅做塞券，不展开触达
- 一个策略完成圈人与补券，降低配置复杂度
- 避免券冗余，用户当前若仍持有 `2.99` 或 `5折`，则不再补发
- 不额外区分用户第二单具体使用了 `2.99` 还是 `5折`，统一补承接券即可

## 三、方案
本次采用统一补 `2.99` 的简化方案。`2.99` 与 `5折` 到手价接近，但 `2.99` 成本更稳定，后台配置更简单，后续效果复盘也更清晰。

圈人规则如下，全部满足 `AND`：
- `首单距今时间 >= 1天`
- `首单距今时间 <= 60天`
- `累计完成订单数 >= 1`
- `累计完成订单数 <= 2`
- `持有优惠券 不包含 新人2.99`
- `持有优惠券 不包含 新人5折`

发券动作：
- 发放 `2.99补券`

策略含义：
针对首单后60天内、仍处于1-2单阶段、且当前手中没有 `2.99` 或 `5折` 的用户，统一补发一张 `2.99`，用于承接其二单或三单转化。

该方案可以覆盖当前新人链路中“已有首单但后续承接券缺失”的核心人群，同时满足“不重复补券、不叠券”的要求。

## 四、执行计划
### 1. 后台配置
基于上述条件建立圈人规则，设置每日自动跑批，对命中用户发放 `2.99补券`。

### 2. 上线方式
先以单策略上线，不叠加更多分支逻辑，保证执行简单、效果可归因。

### 3. 效果观察
重点关注以下指标：
- 首单用户 `T+30 / T+60` 留存
- 自然月次月留存
- 首单后7天、14天、30天二单率
- 首单后30天、60天三单率
- `2.99补券` 领取率、核销率
- 补券用户与非补券用户的留存差异

### 4. 后续优化
若该策略验证有效，再进一步评估是否需要增加补券次数控制、细分二单/三单承接逻辑，或叠加触达策略联动优化。

## 五、评估指标与评估方案

### 1. 评估目标
本次滚动培养落地后的评估，不看“发出去多少券”本身，而看四件事：
- 是否提升 `0→1单` 首单转化
- 是否提升 `1→2单`、`2→3单` 承接效率
- 是否提升 `T+30 / T+60` 留存
- 是否在可接受成本内完成提升

### 2. 指标分层

#### A. 核心结果指标（Primary Metrics）
- `D7 首单转化率`
  定义：注册后 7 天内完成首单的用户占比
  作用：评估 `0→1单` 阶段是否有效
- `D7 二单率`
  定义：首单后 7 天内完成第 2 单的用户占比
  作用：最快反映 `1→2单` 承接是否有效
- `D14 二单率`
  定义：首单后 14 天内完成第 2 单的用户占比
  作用：看 `1→2单` 第一阶段复购的持续拉动
- `D30 三单率`
  定义：首单后 30 天内完成第 3 单的用户占比
  作用：评估 `2→3单` 承接效果
- `D30 留存率`
  定义：首单后 30 天内至少再下 1 单的用户占比
  作用：衡量新客是否真正被留住
- `T+60 留存率`
  定义：首单后 60 天内至少再下 1 单的用户占比
  作用：评估滚动培养是否带来中期留存提升

#### B. 过程指标（Process Metrics）
- `阶段命中率`
  定义：进入某阶段后，实际被策略命中的用户数 / 该阶段应命中用户数
- `发券成功率`
  定义：成功发券用户数 / 应发券用户数
- `提醒送达率`
  定义：成功触达用户数 / 应触达用户数
- `券领取率`
  定义：领取补券用户数 / 成功补券用户数
- `券核销率`
  定义：使用补券用户数 / 成功补券用户数
- `阶段转化率`
  定义：
  - `0→1单`：注册后完成首单用户占比
  - `1→2单`：首单后完成二单用户占比
  - `2→3单`：二单后完成三单用户占比

#### C. 成本与质量指标（Efficiency / Guardrail Metrics）
- `单新增首单成本`
  定义：0→1单阶段补贴成本 / 新增首单用户数
- `单新增二单成本`
  定义：补券总成本 / 新增二单用户数
- `单新增三单成本`
  定义：补券总成本 / 新增三单用户数
- `单新增留存成本`
  定义：补券总成本 / 新增留存用户数
- `补券后客单价 / 单杯实收`
  作用：防止只拉升转化但明显压低收入质量
- `退券/叠券异常率`
  作用：检查是否因为重复发券、券冗余导致策略失真

### 3. 评估方案

#### 3.1 评估对象
- 实验组：命中滚动培养规则且进入当前链路的用户
- 对照组：未进入滚动培养链路的相似新客用户

当前后台没有完整 AB 工具，因此本次默认采用：
- `尾号实验` 作为分流方式
- 先确认 `0-9` 尾号中哪个组的人群质量最接近大盘
- 再选其中 1 个尾号做对照组，其余尾号做实验组

#### 3.2 评估窗口
- `短期观察`：上线后 `D+7`
  看 `D7 首单转化率`、`D7 二单率`、提醒送达率、券领取率、券核销率
- `中期观察`：上线后 `D+14 / D+30`
  看 `D14 二单率`、`D30 三单率`、`D30 留存率`
- `长期观察`：上线后 `T+60`
  看 `T+60 留存率` 与自然月次月留存

#### 3.3 评估节奏
- `首周`
  检查阶段识别是否准确、发券是否正常、提醒链路是否通
- `第2周`
  输出首轮结果：`D7首单转化率 + D7二单率 + 发券成功率 + 券核销率`
- `第4周`
  输出中期结果：`D14二单率 + D30三单率 + D30留存率 + 成本效率`
- `第8周`
  输出完整结果：`T+60留存率 + 自然月次月留存 + ROI判断`

### 4. 复盘输出格式
每次复盘固定输出以下四部分：
- `实验口径`
  说明实验组、对照组、观察窗口、阶段规则、发券和提醒频控
- `核心结果`
  只看 `D7首单转化率 / D7二单率 / D30三单率 / D30留存率 / T+60留存率`
- `过程诊断`
  看阶段命中率、发券成功率、提醒送达率、领取率、核销率，判断问题出在“没识别到”“没发到”“没触达到”“没领”“没用”还是“用了也没转化”
- `成本结论`
  看单新增首单/二单/三单成本、单新增留存成本、客单价/单杯实收是否恶化

### 5. 通过标准（先定义再上线）
本次策略建议用以下门槛判断是否继续放量：
- `D7 首单转化率` 相对对照组为正向
- `D7 二单率` 相对对照组为正向
- `D30 三单率` 相对对照组为正向
- `D30 留存率` 相对对照组为正向
- `券核销率` 不显著低于现有新人券承接水平
- `单杯实收` 不出现明显恶化

只要满足：
- 转化正向
- 留存正向
- 成本可接受

就进入下一步放量或全链路扩展；否则回到补券规则、时间节点或券面设计继续迭代。
