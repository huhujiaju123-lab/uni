# 美国新客循环补丁策略方案（T+60）

## 一、方案边界

- 默认新注册用户首发券包固定为 `1.99 / 2.99 / 3.99 / 5折`
- 本方案只讨论首发券包之后的循环补丁策略
- 本方案覆盖新客首单后 `T+60` 生命周期
- 本方案目标是解决新客二单、三单承接断档，提升次月留存率
- 本方案当前只定义发券策略与触达节奏，不讨论触达文案

## 二、策略目标

- 把新客从首单稳定承接到第3单
- 在首单后 `T+60` 内持续补足二单、三单转化缺口
- 用滚动补券和滚动提醒解决次月留存问题

## 三、核心原则

- 补丁策略不替代首发券包，只负责补承接缺口
- 补丁策略直接覆盖到第3单，不只做二单承接
- 只在用户当前承接券断档时补，不做冗余补券
- 判断逻辑以 `当前订单阶段 + 当前持券状态` 为主
- 发券和触达都采用滚动机制，不是一次性发完
- 同一时刻只跑当前阶段，不并行跑多个阶段
- 用户完成当前目标单后，旧阶段剩余节点全部取消
- 达到第3单后，退出本次新客强提醒主链路

## 四、发券策略

- 覆盖窗口：首单后 `T+60`
- 适用阶段：`1→2单`、`2→3单`
- 补券类型：`2.99` 或 `5折`，并列任选，不分阶段细拆
- 补券频率：每天检查一次，命中则补
- 券有效期：`1天`
- 循环逻辑：当天过期后，若用户仍未完成当前阶段目标，且当前无有效 `2.99` 或 `5折`，次日继续循环补发
- 冗余控制：若用户当前已有有效 `2.99` 或 `5折`，则当天不补

## 五、触达节奏

- 总覆盖周期：注册后至首单后 `T+60`
- 注册后第一周：累计最多提醒 `2次`
- 注册后第二周起：每 `7天` 最多提醒 `1次`
- 同一天最多触达 `1次`
- 若用户完成当前阶段目标单，立即切换到下一阶段节奏
- 若切换时当前周频控额度已满，则顺延到下一个可触达日

## 六、分阶段执行节奏

1. `0→1单`
- 进入条件：新注册，未完成首单
- 目标：推动首单转化
- 触达节点：注册后 `D1`、`D6`
- 退出条件：完成首单后立即退出，切到 `1→2单`

2. `1→2单`
- 进入条件：已完成首单，未完成二单
- 目标：承接二单
- 发券规则：每天检查；若当前无有效 `2.99` 或 `5折`，补发 `2.99或5折` 1张，券有效期 `1天`
- 触达节点：首单后 `D3`、`D7`、`D14`、`D21`、`D30`、`D45`、`D58`
- 退出条件：完成二单后立即退出，切到 `2→3单`；或到首单后 `T+60` 自动退出

3. `2→3单`
- 进入条件：已完成二单，未完成三单
- 目标：承接三单
- 发券规则：每天检查；若当前无有效 `2.99` 或 `5折`，补发 `2.99或5折` 1张，券有效期 `1天`
- 触达节点：二单后 `D3`、`D7`、`D14`、`D21`、`D30`，但整体不超过首单后 `T+60`
- 退出条件：完成三单后立即退出新客强提醒；或到首单后 `T+60` 自动退出

4. `3单后`
- 进入条件：已完成三单
- 目标：退出本次补丁主链路
- 发券动作：不再按新客循环补丁补券
- 触达动作：不再按新客强提醒节奏触达

## 七、统一执行规则

- 每天先判断用户处于哪个订单阶段，再决定是否补券和是否触达
- 每天只允许用户进入一个阶段，不允许阶段并行
- 发券和触达都必须遵守频控，不因节点命中而突破总频次上限
- 本方案的重点不是提高单张券核销率，而是提高二单率、三单率和次月留存率

## 八、效果评估

- 首单后 `7天 / 14天 / 30天` 二单率
- 首单后 `30天 / 60天` 三单率
- 首单后 `T+30 / T+60` 留存
- 自然月次月留存率
- 循环补券领取率、核销率
- 补丁命中用户与非命中用户的留存差异

## 九、一句话口径

默认新客首发 `1.99 / 2.99 / 3.99 / 5折` 4张券后，本方案在首单后 `T+60` 生命周期内，对 `1→2单` 和 `2→3单` 两段承接缺口执行每日滚动补券，并配套首周最多 `2次`、第二周起每周最多 `1次` 的提醒节奏，目标是把新客稳定承接到第3单并提升次月留存率。
