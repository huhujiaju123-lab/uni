# 消息行动收集动作记录

日期：2026-07-20

## 本次目标

搭建一个飞书消息行动收集工作流：定时读取指定群的新消息，提取和李宵霄相关的待办、跟进、开放问题和日程候选，通过飞书交互卡片推送给本人审核，并根据按钮决策记录或创建 Todo / 日程。

## 已配置范围

| 项目 | 当前配置 |
|---|---|
| 监听群 | 美国业务部、美国数据小群 |
| 推送对象 | 李宵霄的韩立 / Codex 机器人单聊 |
| 扫描方式 | 增量读取，先探测每群最新 1 条，有新增再分页读取 |
| 单次上限 | 每群最多 100 条 |
| 推送时间 | 每天 22:00、00:00、02:00、04:00 |
| 空结果 | 也会推送 0 候选卡片 |

## 关键调整

| 问题 | 处理 |
|---|---|
| 每小时全量读 100 条会浪费 token | 改为先读每群最新 1 条，有新增再继续分页 |
| 卡片按钮缺少回调权限 | 启用并验证 `card.action.trigger` |
| 单张卡片只能响应一次 | 停止更新原卡片，改用独立反馈消息 |
| 点击“建 Todo”没有真实创建 | 监听器已接入 `lark-cli task +create` |
| Feishu 事件长连接冲突 | 暂停 `Claude-to-IM` 桥接，保留卡片监听器运行 |

## 当前边界

| 边界 | 说明 |
