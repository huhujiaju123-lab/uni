# 小红书笔记采集器 - 调试指南

## 采集失败的常见原因

### 1. 页面还未加载完成
**解决方法：**
- 等待页面完全加载后再点击采集按钮
- 刷新页面后重试
- 等待 2-3 秒让自动采集功能运行

### 2. 页面选择器不匹配
**原因：** 小红书可能更新了页面结构
**解决方法：** 使用开发者工具查看控制台日志

## 如何查看调试信息

### 步骤一：打开开发者工具

**方法1：快捷键**
- Windows/Linux: 按 `F12` 或 `Ctrl + Shift + I`
- Mac: 按 `Cmd + Option + I`

**方法2：右键菜单**
- 在小红书页面空白处右键
- 选择"检查"或"Inspect"

### 步骤二：查看 Console 控制台

1. 开发者工具打开后，点击顶部的 **Console** 标签
2. 刷新页面，等待 2 秒
3. 查看控制台输出的日志

### 步骤三：查看调试日志

控制台会显示详细的调试信息：

```
✅ 在笔记详情页，开始提取信息...
🔍 开始查找标题...
✅ 找到标题 (h1): 这是笔记标题
🔍 开始查找作者...
✅ 找到作者 (a[href*="/user/"]): 作者名称
🔍 开始查找点赞数...
✅ 找到点赞数 (span[class*="count"]): 1234
📝 最终提取的笔记信息: {title: "...", author: "...", likes: "...", url: "..."}
```

### 步骤四：分析问题

#### 情况 1：显示"❌ 不是笔记详情页"
**原因：** URL 不包含 `/explore/`
**解决方法：**
- 确保你在笔记详情页（点击笔记进入详情后）
- 如果在其他类型的页面，插件暂不支持

#### 情况 2：标题、作者或点赞数为空
**原因：** 选择器没有找到对应元素
**会看到：**
```
=== 页面结构调试信息 ===
URL: https://www.xiaohongshu.com/explore/xxxxx
Title (document.title): 笔记标题
H1 元素数量: 2
  H1[0]: 笔记标题内容
  H1[1]: 其他标题
...
```

**解决方法：** 查看调试信息，找到正确的元素

## 手动修复选择器

如果调试信息显示了正确的内容，但插件没有提取到，你可以手动更新选择器。

### 找到正确的选择器

1. 在开发者工具中，点击左上角的"选择元素"图标（箭头）
2. 点击页面上的标题、作者或点赞数
3. 查看 Elements 标签页中高亮的元素
4. 右键点击元素 → Copy → Copy selector

### 更新 content.js

打开 `content.js` 文件，找到对应的选择器数组，添加你找到的选择器：

```javascript
// 标题选择器（在第 84-93 行左右）
const titleSelectors = [
  '你复制的选择器', // 添加在这里
  '#detail-title',
  '#detail-desc',
  // ...
];

// 作者选择器（在第 124-134 行左右）
const authorSelectors = [
  '你复制的选择器', // 添加在这里
  '[class*="author-name"]',
  // ...
];

// 点赞数选择器（在第 151-159 行左右）
const likeSelectors = [
  '你复制的选择器', // 添加在这里
  '[class*="like-count"]',
  // ...
];
```

### 重新加载扩展

1. 打开 `chrome://extensions/`
2. 找到"小红书笔记采集器"
3. 点击刷新按钮 🔄
4. 返回小红书页面刷新后重试

## 使用浏览器控制台测试

你可以直接在控制台运行采集函数来测试：

```javascript
// 运行采集函数
extractNoteInfo()

// 查看返回结果
```

会显示提取到的信息对象。

## 常见错误信息

### Error: "Cannot read property of undefined"
**原因：** 某个元素不存在
**解决：** 等待页面完全加载

### Error: "chrome.storage is not available"
**原因：** 在非扩展环境中运行
**解决：** 通过点击扩展图标使用

### Error: "Timeout waiting for element"
**原因：** 等待元素超时
**解决：** 页面可能没有该元素，检查页面类型

## 获取帮助

### 步骤 1：截图控制台信息
1. 打开开发者工具 Console
2. 截图所有日志信息
3. 包含完整的"页面结构调试信息"

### 步骤 2：检查页面 URL
确认你访问的页面 URL 格式是：
```
https://www.xiaohongshu.com/explore/xxxxxxxxxx
```

### 步骤 3：检查扩展版本
在 `chrome://extensions/` 页面确认：
- 扩展已启用
- 版本号为 1.0.0
- 没有错误提示

## 高级调试

### 查看 Popup 日志

1. 点击扩展图标打开弹窗
2. 右键点击弹窗空白处
3. 选择"检查"
4. 查看新的开发者工具窗口的 Console

### 查看存储的数据

在控制台运行：
```javascript
chrome.storage.local.get(['notes'], (result) => {
  console.log('存储的笔记:', result.notes);
});
```

### 清空存储数据

如果数据损坏，可以清空：
```javascript
chrome.storage.local.clear(() => {
  console.log('存储已清空');
});
```
