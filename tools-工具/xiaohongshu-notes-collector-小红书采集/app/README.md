# 小红书笔记采集器 Chrome 扩展

一个功能强大的 Chrome 浏览器扩展，帮助你轻松采集和管理小红书笔记信息。

## 功能特性

- **自动采集** - 访问小红书笔记页面时自动采集信息
- **手动采集** - 点击按钮立即采集当前笔记
- **数据持久化** - 所有数据保存在本地，不会丢失
- **智能去重** - 相同链接的笔记会自动更新而非重复保存
- **数据导出** - 一键导出为 CSV 格式，方便在 Excel 中查看
- **统计功能** - 实时显示总采集数和今日新增数
- **精美界面** - 小红书主题配色，使用体验优雅

## 采集的信息

每条笔记会采集以下信息：

1. **标题** - 笔记的标题内容
2. **作者** - 发布笔记的用户名
3. **点赞数** - 笔记获得的点赞数量
4. **链接** - 笔记的完整 URL
5. **采集时间** - 记录采集的具体时间

## 安装步骤

### 第一步：准备文件

确保你的项目文件夹 `xiaohongshu-notes-collector` 包含以下文件：

```
xiaohongshu-notes-collector/
├── manifest.json          # 扩展配置文件
├── content.js            # 页面内容采集脚本
├── popup.html            # 弹窗界面
├── popup.js              # 弹窗交互逻辑
├── icons/                # 图标文件夹
│   ├── icon16.png
│   ├── icon48.png
│   └── icon128.png
└── README.md             # 说明文档
```

### 第二步：在 Chrome 中加载扩展

1. **打开 Chrome 扩展管理页面**
   - 方法1：在地址栏输入 `chrome://extensions/` 并回车
   - 方法2：点击 Chrome 菜单 → 更多工具 → 扩展程序

2. **启用开发者模式**
   - 在页面右上角找到"开发者模式"开关
   - 点击开关，确保其处于启用状态（蓝色）

3. **加载扩展**
   - 点击"加载已解压的扩展程序"按钮
   - 在文件选择器中，找到并选择 `xiaohongshu-notes-collector` 文件夹
   - 点击"选择"或"打开"

4. **确认安装成功**
   - 扩展列表中会出现"小红书笔记采集器"
   - Chrome 工具栏会出现扩展图标（红色背景）

### 第三步：固定扩展图标（可选）

1. 点击 Chrome 工具栏右侧的拼图图标（扩展）
2. 找到"小红书笔记采集器"
3. 点击图标右侧的图钉，将其固定到工具栏

## 使用方法

### 方式一：自动采集

1. 访问任意小红书笔记页面（URL 包含 `/explore/`）
2. 页面加载完成后，扩展会自动采集笔记信息
3. 点击扩展图标查看采集结果

### 方式二：手动采集

1. 访问小红书笔记页面
2. 点击扩展图标打开弹窗
3. 点击"📌 采集当前笔记"按钮
4. 等待采集完成，会显示成功提示

### 查看采集的笔记

1. 点击扩展图标打开弹窗
2. 在弹窗中可以看到：
   - **统计数据**：已采集总数、今日新增数
   - **笔记列表**：显示所有采集的笔记
   - 每条笔记包含标题、作者、点赞数、链接和采集时间

### 导出数据

1. 点击扩展图标打开弹窗
2. 点击"📥 导出为CSV"按钮
3. CSV 文件会自动下载到默认下载文件夹
4. 文件名格式：`小红书笔记采集_2024-01-15T10-30-45.csv`

### 导出的 CSV 格式

CSV 文件包含以下列：

| 序号 | 标题 | 作者 | 点赞数 | 链接 | 采集时间 |
|-----|------|------|--------|------|---------|
| 1   | xxx  | xxx  | 1234   | url  | 时间    |

可以直接用 Excel、WPS、Numbers 等软件打开查看和编辑。

### 清空数据

1. 点击扩展图标打开弹窗
2. 点击"🗑️ 清空数据"按钮
3. 在确认对话框中点击"确定"
4. 所有采集的数据会被清空（此操作不可恢复）

## 常见问题

### Q1: 点击采集按钮没有反应？

**可能原因和解决方法：**
- 确保你在小红书笔记页面（URL 包含 `xiaohongshu.com`）
- 等待页面完全加载后再点击采集
- 刷新页面后重试
- 查看 Chrome 开发者工具控制台是否有错误信息

### Q2: 采集的信息不完整？

**原因：** 小红书页面结构可能更新

**解决方法：**
- 打开 Chrome 开发者工具（F12）
- 查看 Console 标签页的日志信息
- 可能需要更新 `content.js` 中的选择器

### Q3: 导出的 CSV 文件乱码？

**解决方法：**
- 使用 Excel 打开时，选择"UTF-8"编码
- 或者用记事本打开后另存为 ANSI 编码
- 推荐使用 WPS 或 Numbers，会自动识别编码

### Q4: 扩展图标不显示？

**解决方法：**
- 检查 `icons` 文件夹中是否有图标文件
- 运行 `python3 create_icons.py` 重新生成图标
- 或手动创建 16x16、48x48、128x128 的 PNG 图标

### Q5: 采集的数据会丢失吗？

**不会！** 数据保存在 Chrome 的本地存储中，除非：
- 手动点击"清空数据"
- 卸载扩展
- 清除浏览器数据时选择了扩展数据

建议定期导出数据做备份。

## 技术说明

### 文件功能

- **manifest.json** - Chrome 扩展配置，定义权限和资源
- **content.js** - 注入到小红书页面的脚本，负责提取信息
- **popup.html** - 扩展弹窗界面的 HTML 结构
- **popup.js** - 弹窗的交互逻辑和数据管理
- **icons/** - 扩展在不同场景显示的图标

### 权限说明

扩展需要以下权限：

- **storage** - 用于在本地保存采集的数据
- **activeTab** - 用于访问当前活动标签页
- **scripting** - 用于注入内容脚本
- **host_permissions** - 仅在小红书网站生效

### 数据存储

数据使用 `chrome.storage.local` API 存储，特点：

- 仅保存在本地，不会上传到任何服务器
- 容量限制约 10MB，足够存储大量笔记
- 即使关闭浏览器，数据也不会丢失

## 开发相关

### 修改和调试

如果需要修改代码：

1. 编辑对应的文件
2. 回到 `chrome://extensions/` 页面
3. 找到本扩展，点击刷新图标
4. 重新测试功能

### 查看日志

打开 Chrome 开发者工具：

- **Content Script 日志**：在小红书页面按 F12，查看 Console
- **Popup 日志**：右键点击扩展图标 → 检查弹出内容

### 更新选择器

如果小红书页面结构变化，可能需要更新 `content.js` 中的选择器：

```javascript
// 标题选择器
const titleSelectors = [
  '#detail-title',
  '[class*="title"]',
  'h1'
];

// 作者选择器
const authorSelectors = [
  '[class*="author-name"]',
  '[class*="username"]'
];

// 点赞数选择器
const likeSelectors = [
  '[class*="like-count"]',
  '[aria-label*="赞"] span'
];
```
