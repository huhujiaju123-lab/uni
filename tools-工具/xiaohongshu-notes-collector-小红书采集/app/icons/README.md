# 图标文件说明

## 需要的图标尺寸

为了插件能正常显示，需要创建以下三个尺寸的 PNG 图标：

1. **icon16.png** - 16x16 像素
2. **icon48.png** - 48x48 像素
3. **icon128.png** - 128x128 像素

## 快速解决方案

### 方法1：使用在线图标生成器
访问以下网站可以快速生成图标：
- https://www.favicon-generator.org/
- https://realfavicongenerator.net/

上传一张图片（建议使用小红书相关的红色主题图标），生成不同尺寸即可。

### 方法2：使用现有图片
如果你有一张图片（PNG/JPG），可以使用以下工具调整大小：
- Photoshop
- GIMP（免费）
- 在线工具：https://www.iloveimg.com/resize-image

### 方法3：临时使用纯色图标
在开发阶段，可以先使用纯色图标占位。

## 图标设计建议

- 使用小红书的品牌色：#FF2442（红色）
- 可以使用 📌 或 📝 等表情符号作为灵感
- 保持简洁，在小尺寸下也要清晰可见
