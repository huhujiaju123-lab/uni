  小红书笔记采集器 - 快速安装指南
═══════════════════════════════════════════════

📦 第一步：确认文件
────────────────────────────────────────
当前文件夹应包含以下文件：
  ✓ manifest.json
  ✓ content.js
  ✓ popup.html
  ✓ popup.js
  ✓ icons/ 文件夹（包含 3 个图标文件）
  ✓ README.md


🔧 第二步：安装扩展到 Chrome
────────────────────────────────────────
1. 打开 Chrome 浏览器

2. 在地址栏输入：chrome://extensions/
   然后按回车键

3. 在页面右上角，打开「开发者模式」开关
   （开关应该变成蓝色）

4. 点击左上角的「加载已解压的扩展程序」按钮

5. 在弹出的文件选择器中：
   - 找到 xiaohongshu-notes-collector 文件夹
   - 选中这个文件夹
   - 点击「选择」或「打开」

6. 如果成功，你会看到：
   ✓ 扩展列表中出现「小红书笔记采集器」
   ✓ Chrome 工具栏出现红色图标


💡 第三步：开始使用
────────────────────────────────────────
【方式一：自动采集】
  1. 访问小红书笔记页面
  2. 等待 2 秒，自动采集完成
  3. 点击扩展图标查看结果

【方式二：手动采集】
  1. 访问小红书笔记页面
  2. 点击扩展图标
  3. 点击「📌 采集当前笔记」按钮


📤 导出数据
────────────────────────────────────────
1. 点击扩展图标打开弹窗
2. 点击「📥 导出为CSV」按钮
3. CSV 文件会自动下载
4. 用 Excel 打开查看数据


⚠️ 注意事项
────────────────────────────────────────
• 只在小红书笔记页面才能采集
• 数据保存在浏览器本地，不会丢失
• 建议定期导出备份
• 相同链接的笔记不会重复保存


❓ 遇到问题？
────────────────────────────────────────
• 采集失败：刷新页面后重试
• 图标不显示：检查 icons 文件夹
• 数据乱码：用 WPS 或 Numbers 打开 CSV

详细说明请查看 README.md 文件
