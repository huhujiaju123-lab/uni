# 小红书笔记采集器 - 列表页采集使用说明

## ✨ 更新内容

插件已升级为**列表页自动采集模式**，现在可以：

✅ 在探索页面自动采集所有显示的笔记
✅ 滚动加载时自动采集新出现的笔记
✅ 智能去重，不会重复保存相同笔记
✅ 后台持续监听，无需手动操作

## 🚀 使用方法

### 第一步：重新加载扩展

1. 打开 `chrome://extensions/`
2. 找到"小红书笔记采集器"
3. 点击刷新按钮 🔄

### 第二步：访问小红书

1. 打开小红书网站：https://www.xiaohongshu.com/
2. 进入**探索页面**或**首页**（有笔记列表的任何页面）
3. 等待 2-3 秒，插件会自动开始采集

### 第三步：查看控制台日志

按 F12 打开开发者工具，在 Console 标签页会看到：

```
🚀 小红书笔记采集器已加载 (列表页模式)
📍 当前页面: https://www.xiaohongshu.com/explore
✅ 已加载 0 条历史记录
🔍 开始首次采集...
🔍 使用选择器 "a[href*="/explore/"]" 找到 20 个元素
📝 提取笔记: {title: "笔记标题", author: "作者", likes: "123"}
✅ 保存新笔记: 笔记标题
✅ 本次采集到 20 条新笔记
👀 页面监听器已启动，将自动采集新加载的笔记
📜 滚动监听器已启动
```

### 第四步：滚动浏览

1. 继续向下滚动页面
2. 小红书会自动加载更多笔记
3. 插件会自动采集新出现的笔记
4. 控制台会显示：
   ```
   🔄 检测到页面变化，重新采集...
   ✅ 本次采集到 10 条新笔记
   ```

### 第五步：查看和导出

1. 点击扩展图标
2. 查看已采集的笔记列表
3. 点击"📥 导出为CSV"下载数据

## 🎯 采集的信息

每条笔记包含：

- **标题** - 笔记的标题或描述
- **作者** - 发布者的用户名
- **点赞数** - 点赞数量（如果页面显示）
- **链接** - 笔记详情页链接
- **采集时间** - 记录采集的时间

## 💡 使用技巧

### 1. 批量采集
- 不断滚动页面，浏览更多笔记
- 插件会自动采集所有出现的笔记
- 可以切换不同的分类标签采集

### 2. 避免重复
- 已经采集过的笔记不会重复保存
- 即使刷新页面，也会记住已采集的笔记
- 控制台会显示"已加载 X 条历史记录"

### 3. 手动触发
- 如果自动采集没有触发
- 点击扩展图标
- 点击"📌 采集当前笔记"按钮

### 4. 查看进度
- 实时查看控制台日志
- 了解采集进度和数量
- 发现问题及时调试

## 🔧 调试和优化

### 如果没有自动采集

1. **检查控制台日志**
   - 打开 F12 开发者工具
   - 查看是否有错误信息

2. **查看找到的元素数量**
   ```
   🔍 使用选择器 "..." 找到 X 个元素
   ```
   - 如果数量为 0，说明选择器需要更新

3. **手动触发调试**
   - 在控制台运行：`collectNotesOnPage()`
   - 查看输出的调试信息

### 如果采集的信息不完整

某些笔记可能缺少作者或点赞数，这是正常的：

- 小红书页面结构可能不一致
- 有些信息在列表页不显示
- 可以进入详情页获取更完整信息

### 性能优化

插件已经做了防抖处理：

- 滚动停止 500ms 后才触发采集
- 页面变化后 1000ms 才触发采集
- 避免频繁操作影响性能

## 📊 数据管理

### 查看统计
- 总采集数：所有采集的笔记总数
- 今日新增：今天采集的笔记数

### 导出数据
- CSV 格式，可用 Excel 打开
- 包含所有字段和采集时间
- 文件名自动带时间戳

### 清空数据
- 点击"🗑️ 清空数据"
- 会清空所有采集记录
- 操作不可恢复，谨慎使用

## ⚠️ 注意事项

1. **合理使用**
   - 仅用于个人学习和研究
   - 不要用于商业用途
   - 遵守小红书服务条款

2. **页面兼容**
   - 支持小红书探索页、首页等列表页
   - 不同页面的结构可能不同
   - 如遇问题，查看控制台调试

3. **数据准确性**
   - 数据来源于页面显示内容
   - 可能因页面结构变化而不准确
   - 定期检查和更新选择器

4. **存储限制**
   - Chrome 本地存储约 10MB
   - 可存储数千条笔记
   - 建议定期导出备份

## 🆘 常见问题

### Q: 为什么有些笔记没有作者或点赞数？

A: 列表页展示的信息有限，部分字段可能获取不到。如需完整信息，可以进入详情页。

### Q: 滚动后为什么没有自动采集？

A:
- 检查控制台是否有"🔄 检测到页面变化"日志
- 页面可能使用了虚拟滚动，需要等待加载
- 手动点击"采集当前笔记"按钮

### Q: 可以采集其他页面吗？

A: 可以，只要页面上有笔记链接（包含 `/explore/`），都可以尝试采集。

### Q: 数据会丢失吗？

A: 数据保存在浏览器本地存储，不会丢失。除非：
- 手动清空数据
- 卸载扩展
- 清除浏览器数据

### Q: 如何更新选择器？

A: 如果页面结构变化，可以：
1. 打开 content.js 文件
2. 修改对应的选择器数组
3. 重新加载扩展
