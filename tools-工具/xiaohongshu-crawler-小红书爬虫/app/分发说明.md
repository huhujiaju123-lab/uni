2. **打开Chrome扩展页面**

   - 访问小红书即可使用

## ⚠️ 常见问题提醒

### 图标显示问题
当前使用的是临时图标（紫色圆形）。如果想要更精美的图标：

```bash
# 在浏览器中打开
open icons/icon-generator.html

# 下载生成的新图标，替换icons/文件夹中的4个PNG文件
# 然后重新运行 ./package.sh 打包
```

### 为什么有些人说"不兼容"？

**常见误解：**
1. ❌ 对方没开启"开发者模式"
2. ❌ 对方Chrome版本过低（需要88+）
3. ❌ 对方选错了文件夹（应选包含manifest.json的文件夹）
4. ❌ 对方解压出错

**解决方案：**
发送时附上 `安装说明.txt`，让用户按步骤操作。
