# 小红书抓取工具 - 调试指南

## 🔧 如何测试详情页抓取功能

### 第一步：重新加载扩展
每次修改代码后，必须重新加载扩展：
1. 打开 `chrome://extensions/`
2. 找到"小红书笔记抓取工具"
3. 点击刷新按钮 🔄

### 第二步：打开小红书详情页
1. 访问小红书网站：https://www.xiaohongshu.com
2. 在首页或搜索结果中**点击某一篇笔记**
3. 确保进入了完整的笔记详情页面（能看到完整内容和评论区）

✅ **正确的详情页URL示例**：
- `https://www.xiaohongshu.com/explore/xxxxx`
- `https://www.xiaohongshu.com/discovery/item/xxxxx`
- `https://www.xiaohongshu.com/note/xxxxx`

❌ **错误的页面**（不能使用详情页抓取）：
- 首页/搜索结果页（只有笔记卡片列表）
- 用户主页
- 话题页

### 第三步：查看浏览器控制台
1. 在详情页按 `F12` 打开开发者工具
2. 切换到 **Console（控制台）** 标签
3. 点击扩展的"抓取当前详情页"按钮
4. 观察控制台输出的日志

### 预期的控制台日志

**成功的情况**：
```
[详情页抓取] 开始抓取，当前URL: https://www.xiaohongshu.com/explore/xxxxx
[详情页抓取] 确认是详情页，开始提取数据...
[详情页抓取] 标题提取成功: [笔记标题]
[详情页抓取] 内容提取成功，长度: 123
[详情页抓取] 开始提取评论...
[详情页抓取] 找到评论容器: [class*="comment"]
[详情页抓取] 找到评论项: 10 条
[详情页抓取] 评论提取完成，共 10 条
[详情页抓取] 抓取完成: {url: "...", contentTitle: "...", ...}
```

**不在详情页的情况**：
```
[详情页抓取] 开始抓取，当前URL: https://www.xiaohongshu.com/
[详情页抓取] 不是详情页，URL不符合
```

## 🐛 常见问题排查

### 问题1：点击按钮没有反应

**可能原因**：
- 扩展没有重新加载
- content.js 没有正确注入

**解决方法**：
1. 重新加载扩展
2. 刷新小红书页面
3. 检查控制台是否有JavaScript错误

### 问题2：提示"不在详情页"

**可能原因**：
- 你在列表页而不是详情页

**解决方法**：
1. 点击某一篇笔记卡片，进入完整内容页
2. 确保URL包含 `/explore/` 或 `/note/`

### 问题3：标题/内容抓取为空

**可能原因**：
- 页面还没完全加载
- 小红书DOM结构发生变化
- 内容被动态加载

**调试方法**：
1. 打开控制台（F12）
2. 在 Console 中输入以下命令查看DOM结构：

```javascript
// 查看页面中所有包含"title"的元素
document.querySelectorAll('[class*="title"]')

// 查看页面中所有h1标签
document.querySelectorAll('h1')

// 查看页面中包含大量文本的div
Array.from(document.querySelectorAll('div')).filter(d => d.textContent.length > 50)
```

3. 如果能找到内容元素，记下它的class或id
4. 告诉我选择器，我会更新代码

### 问题4：评论数量为0

**可能原因**：
- 评论区还没加载
- 评论需要手动展开

**解决方法**：
1. 在详情页向下滚动到评论区
2. 点击"展开更多评论"
3. 等待评论加载完成
4. 再点击抓取按钮

**调试方法**：
在控制台输入：
```javascript
// 查找评论容器
document.querySelectorAll('[class*="comment"]')

// 查看评论项
document.querySelectorAll('[class*="comment-item"]')
```

## 📋 手动测试抓取功能

如果自动抓取不工作，可以在控制台手动测试：

### 测试详情页抓取
在笔记详情页的控制台中运行：

```javascript
// 测试标题提取
const h1 = document.querySelector('h1');
console.log('标题:', h1 ? h1.textContent : '未找到');

// 测试内容提取
const content = document.querySelector('[class*="desc"]');
console.log('内容:', content ? content.textContent : '未找到');

// 测试评论提取
const comments = document.querySelectorAll('[class*="comment"]');
console.log('评论区元素:', comments.length);
```

### 测试列表页抓取
在列表页的控制台中运行：

```javascript
// 查看所有笔记卡片
const cards = document.querySelectorAll('div:has(a[href*="/explore/"])');
console.log('找到', cards.length, '个笔记卡片');

// 查看第一个卡片的链接
const firstCard = cards[0];
const link = firstCard.querySelector('a[href*="/explore/"]');
console.log('第一个笔记链接:', link ? link.href : '未找到');
```

如果抓取还是不工作，请提供以下信息：

1. **页面URL**：你正在抓取的笔记链接
2. **控制台日志**：
   - 按F12打开控制台
   - 复制所有以 `[详情页抓取]` 开头的日志
3. **DOM结构**：
   - 在Elements标签中查看笔记标题、内容、评论的HTML结构
   - 记下它们的class名称或id

## 💡 提高抓取成功率的技巧

1. **确保页面完全加载**
   - 等待页面加载完成（不再有加载动画）
   - 滚动到评论区，让评论加载出来

2. **手动展开内容**
   - 如果内容有"展开全文"按钮，先点击展开
   - 如果评论有"查看更多"，先展开

3. **检查网络状态**
   - 确保网络正常，小红书页面能正常访问
   - 如果页面加载慢，多等一会儿

4. **使用控制台日志**
   - 始终打开控制台查看详细日志
   - 日志会告诉你每一步的执行情况
