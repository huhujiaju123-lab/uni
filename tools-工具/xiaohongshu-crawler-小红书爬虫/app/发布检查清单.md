## 🎨 图标生成步骤

**必须在打包前完成！**

1. 在浏览器中打开 `icons/icon-generator.html`
   ```bash
   open icons/icon-generator.html
   ```

2. 页面会自动生成4个尺寸的图标

3. 点击"下载所有图标"按钮

4. 将下载的4个PNG文件放到 `icons/` 文件夹中：
   - icon16.png
   - icon32.png
   - icon48.png
   - icon128.png

5. 验证图标是否生成成功：
   ```bash
   ls -la icons/
   # 应该看到5个文件：
   # - icon-generator.html
   # - icon16.png
   # - icon32.png
   # - icon48.png
   # - icon128.png
   ```

## 🚀 打包步骤

### 方法1：使用打包脚本（推荐）

```bash
# 进入项目目录
cd /Users/xiaoxiao/Desktop/编程/xiaohongshu-crawler

# 运行打包脚本
./package.sh

# 检查生成的ZIP文件
ls -lh xiaohongshu-crawler-v3.0.zip
```

**脚本会自动：**
- ✅ 创建临时打包目录
- ✅ 复制必需文件
- ✅ 删除.DS_Store等临时文件
- ✅ 检查图标文件是否存在
- ✅ 生成ZIP文件
- ✅ 清理临时目录

### 方法2：手动打包

```bash
# 创建ZIP文件（不包含开发文档）
zip -r xiaohongshu-crawler-v3.0.zip \
  manifest.json \
  background.js \
  content/ \
  popup/ \
  icons/ \
  PRIVACY_POLICY.md \
  -x "*.DS_Store" \
  -x "*/.*"
```
