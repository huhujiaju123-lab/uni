# 小红书笔记抓取工具 v2.0 使用说明

## 📋 功能概述

这是一个功能强大的Chrome浏览器扩展，用于抓取小红书笔记数据，支持列表页和详情页双重抓取模式。

### 新增功能 (v2.0)

✅ **列表页自动滚动加载**：自动滚动到底部，确保所有加载的笔记都被抓取，不会遗漏
✅ **详情页内容抓取**：抓取笔记正文标题、完整内容和所有评论
✅ **评论详情提取**：包括评论者用户名、评论内容、点赞数
✅ **双数据源管理**：列表数据和详情数据分别存储和展示
✅ **增强CSV导出**：导出文件包含列表数据和详情数据两个部分

## 🚀 安装方法

1. 打开Chrome浏览器，进入 `chrome://extensions/`
2. 开启右上角的"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择 `xiaohongshu-crawler` 文件夹
5. 扩展安装完成！

## 📖 使用方法

### 1️⃣ 抓取列表页笔记

**适用场景**：在小红书搜索结果页、用户主页、话题页等列表页面

**操作步骤**：
1. 打开小红书网站（www.xiaohongshu.com）
2. 浏览到需要抓取的笔记列表页（如搜索结果、用户主页）
3. 点击浏览器工具栏中的扩展图标
4. 点击【抓取列表页笔记】按钮
5. 等待自动滚动加载（页面会自动滚动到底部加载所有笔记）
6. 抓取完成后会显示成功提示

**抓取数据**：
- 作者名称
- 点赞数量
- 笔记标题
- 笔记链接

### 2️⃣ 抓取详情页内容

**适用场景**：在单个笔记的详情页面

**操作步骤**：
1. 打开某一篇笔记的详情页（URL包含 `/explore/` 或 `/discovery/item/`）
2. 等待页面完全加载（包括评论区）
3. 点击浏览器工具栏中的扩展图标
4. 点击【抓取当前详情页】按钮
5. 抓取完成后会自动切换到"详情数据"标签

**抓取数据**：
- 笔记正文标题
- 笔记完整内容
- 评论总数
- 评论详情列表：
  - 评论者用户名
  - 评论内容
  - 评论点赞数

### 3️⃣ 查看已保存的数据

**列表数据标签**：
- 显示所有抓取的列表页笔记
- 以表格形式展示：作者、点赞数、标题、链接

**详情数据标签**：
- 显示所有抓取的详情页数据
- 以表格形式展示：正文标题、正文内容预览、评论数
- 点击【查看评论】按钮可查看该笔记的所有评论详情

### 4️⃣ 导出CSV文件

1. 点击【下载所有数据为CSV】按钮
2. 自动下载CSV文件，文件名格式：`小红书笔记数据_时间戳.csv`
3. CSV文件包含两个部分：
   - **列表页数据**：作者、点赞数、标题、链接
   - **详情页数据**：链接、正文标题、正文内容、评论数、评论详情

## ⚙️ 技术特性

### 智能滚动加载
- 自动检测页面高度变化
- 连续3次高度不变则停止滚动
- 滚动完成后自动返回顶部
- 确保所有动态加载的笔记都被抓取

### 数据去重机制
- 列表数据：根据笔记链接去重
- 详情数据：根据笔记URL去重
- 多次抓取不会产生重复数据

### 兼容性优化
- 兼容多种DOM结构和class命名
- 支持小红书PC端和移动端页面
- 智能识别列表页和详情页

## 💡 使用技巧

1. **批量抓取列表数据**：
   - 在搜索结果页向下滚动加载更多笔记
   - 点击抓取按钮会自动继续滚动到底
   - 适合批量收集某个话题或关键词的笔记

2. **深度抓取评论**：
   - 在详情页手动展开"查看更多评论"
   - 滚动到评论区底部加载更多评论
   - 再点击抓取详情页按钮

3. **数据管理**：
   - 数据保存在浏览器本地存储中
   - 关闭浏览器后数据不会丢失
   - 可随时导出CSV文件备份

## 📊 CSV文件格式

### 列表页数据字段
```
作者,点赞数,标题,链接
"用户A","1234","笔记标题","https://..."
```

### 详情页数据字段
```
链接,正文标题,正文内容,评论数,评论详情
"https://...","标题","正文内容","10","[用户1] 评论1 (赞:5); [用户2] 评论2 (赞:3);"
```

## ⚠️ 注意事项

1. **页面加载**：确保页面完全加载后再进行抓取
2. **滚动等待**：列表页自动滚动需要一些时间，请耐心等待
3. **评论加载**：详情页抓取前，建议手动加载更多评论
4. **数据安全**：请遵守小红书的使用条款，合理使用抓取功能
5. **浏览器限制**：仅支持Chrome浏览器及基于Chromium的浏览器
