## 📝 上架步骤

### 第一步：注册开发者账号

1. 访问 [Chrome Web Store 开发者控制台](https://chrome.google.com/webstore/devconsole)
2. 使用Google账号登录
3. 支付 **5美元** 一次性注册费（使用信用卡/PayPal）
4. 填写开发者信息

**重要提示：**
- 这是一次性费用，之后可以无限上架扩展
- 使用稳定的Google账号
- 记住开发者账号信息

### 第二步：准备图标

```bash
# 1. 打开图标生成器
open icons/icon-generator.html

# 2. 下载生成的图标
# 确保 icons/ 文件夹中有以下文件：
# - icon16.png
# - icon32.png
# - icon48.png
# - icon128.png
```

### 第三步：制作截图

**方法1：手动截图**
1. 在Chrome中加载扩展
2. 打开小红书网站
3. 使用截图工具（推荐：Snipaste、截图工具）
4. 截取5张不同场景的图片

**方法2：使用浏览器开发工具**
1. 按F12打开开发工具
2. 使用设备模拟器调整尺寸为 1280x800
3. 截取屏幕

**截图建议：**
- 使用真实的小红书页面
- 展示实际抓取的数据
- 界面清晰，文字可读
- 突出核心功能

### 第四步：打包扩展

```bash
# 进入项目目录
cd /Users/xiaoxiao/Desktop/编程/xiaohongshu-crawler

# 创建zip文件（不包含以下文件）
# - .DS_Store
# - 使用说明.md
# - 调试指南.md
# - v3.0更新说明.md
# - 上架指南.md
# - STORE_LISTING.md

# 方法1：使用Finder
# 1. 选择需要打包的文件和文件夹
# 2. 右键 -> 压缩

# 方法2：使用命令行
zip -r xiaohongshu-crawler.zip \
  manifest.json \
  background.js \
  content/ \
  popup/ \
  icons/ \
  PRIVACY_POLICY.md \
  -x "*.DS_Store"
```

**需要打包的文件：**
```
xiaohongshu-crawler/
├── manifest.json          ✅
├── background.js          ✅
├── content/
│   └── content.js        ✅
├── popup/
│   ├── popup.html        ✅
│   ├── popup.js          ✅
│   └── popup.css         ✅
├── icons/
│   ├── icon16.png        ✅
│   ├── icon32.png        ✅
│   ├── icon48.png        ✅
│   └── icon128.png       ✅
└── PRIVACY_POLICY.md     ✅（可选，但推荐）
```

### 第五步：上传扩展

1. 访问 [Chrome Web Store 开发者控制台](https://chrome.google.com/webstore/devconsole)
2. 点击 **"新增项"** 或 **"New Item"**
3. 上传打包好的 zip 文件
4. 等待上传完成

## ⏱️ 审核时间

- **首次审核**：通常需要 **1-3天**
- **更新审核**：通常需要 **几小时到1天**

## 📋 审核检查清单

在提交前，确保：

- [ ] 所有图标尺寸正确且清晰
- [ ] 至少有1张高质量截图
- [ ] 描述清晰准确，无语法错误
- [ ] 隐私政策链接可访问
- [ ] 扩展功能与描述一致
- [ ] 没有侵犯版权的内容
- [ ] 权限说明清楚合理
- [ ] 扩展在本地测试无bug

## ⚠️ 常见拒绝原因

### 1. 图标问题
- 图标模糊或低质量
- 图标尺寸不正确
- 图标与扩展功能不符

**解决方案：**
- 使用高质量PNG图标
- 确保所有尺寸都清晰

### 2. 描述问题
- 描述包含误导性内容
- 过度使用关键词
- 包含外部链接

**解决方案：**
- 如实描述功能
- 自然使用关键词
- 避免外部链接

### 3. 隐私问题
- 缺少隐私政策
- 隐私政策链接失效
- 权限说明不清

**解决方案：**
- 提供详细的隐私政策
- 确保链接可访问
- 清楚说明每个权限的用途

### 4. 功能问题
- 扩展功能不工作
- 与描述不符
- 存在bug

**解决方案：**
- 充分测试
- 确保功能正常
- 修复所有已知bug
