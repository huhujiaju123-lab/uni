## ⚠️ 常见拒绝原因与解决方案

### 1. 图标问题

**原因：**
- 图标模糊或低质量
- 图标尺寸不正确
- 图标不符合政策

**解决：**
```bash
# 重新生成高质量图标
open icons/icon-generator.html
# 下载新图标
# 重新打包
./package.sh
# 重新上传
```

### 2. 描述问题

**原因：**
- 描述夸大或误导
- 包含外部链接
- 过度使用关键词

**解决：**
- 如实描述功能
- 删除外部链接
- 自然使用关键词

### 3. 隐私政策问题

**原因：**
- 链接失效
- 内容不完整
- 与实际功能不符

**解决：**
- 确保链接可访问
- 补充完整说明
- 与功能保持一致

### 4. 权限问题

**原因：**
- 权限说明不清
- 请求了不必要的权限
- 权限与功能不匹配

**解决：**
- 详细说明每个权限用途
- 删除不必要的权限
- 确保说明准确

### 5. 功能问题

**原因：**
- 扩展功能不正常
- 存在bug
- 与描述不符

**解决：**
- 充分测试后再提交
- 修复所有已知bug
- 确保功能完整
