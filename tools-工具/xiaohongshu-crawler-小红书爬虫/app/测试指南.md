## 🚀 加载扩展到Chrome

### 步骤1：打开Chrome扩展管理页面

**方法1：地址栏直接访问**
```
chrome://extensions/
```

**方法2：菜单访问**
- 点击Chrome右上角的三点菜单
- 选择"更多工具" → "扩展程序"

### 步骤2：开启开发者模式

- 在扩展管理页面右上角找到"开发者模式"开关
- 点击开启（开关变为蓝色）

### 步骤3：加载扩展

1. 点击页面左上角的 **"加载已解压的扩展程序"** 按钮
2. 在弹出的文件选择窗口中，导航到：
   ```
   /Users/xiaoxiao/Desktop/编程/xiaohongshu-crawler/test-extension
   ```
3. 选择 `test-extension` 文件夹
4. 点击"选择"或"打开"按钮

### 步骤4：验证加载成功

加载成功后，你应该看到：
- ✅ 扩展卡片出现在列表中
- ✅ 名称显示：**小红书笔记抓取工具**
- ✅ 版本显示：**3.0.0**
- ✅ 图标显示：紫色圆形图标
- ✅ 状态显示：**已启用**
