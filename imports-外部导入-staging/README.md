# imports-外部导入-staging

这个目录用于承接外部目录导入过程中的中间态内容，避免未分类文件直接污染正式架构。

## 当前分区

- `desktop-桌面导入/`
  - 桌面副本、历史版本、尚未完全分类的导入内容
- `external-repos-外部仓库/`
  - 原始仓库归档、导入时拆出的元数据、历史过程文件
- `private-configs-私有配置/`
  - 从小程序和本地项目中移出的 `project.private.config.json` 等私有配置

## 清理规则

1. staging 目录不是最终归宿；导入完成后应继续向正式目录消化。
2. 私有配置不回流主项目目录，除非明确改造成模板或示例配置。
3. 若某个目录长期无法分类，应补一份说明文件，而不是直接散放。
