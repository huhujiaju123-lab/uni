# Style Notes

Use this file to capture visual rules from user-provided reference samples.

Default style:

- Report type: internal business review
- Tone: direct, decision-oriented, no decorative copywriting
- Visual density: one conclusion card, one metric block, one comparison chart, one funnel diagnosis
- Color intent:
  - green: positive or healthy
  - amber: warning or inconclusive
  - red: risk or negative
  - gray: baseline/control
- Chart labels: Chinese business terms first
- Tables: compact, only include decision-relevant columns

When a user provides a new sample, update this file with:

- layout pattern
- color palette
- chart types
- wording style
- what should not be copied
