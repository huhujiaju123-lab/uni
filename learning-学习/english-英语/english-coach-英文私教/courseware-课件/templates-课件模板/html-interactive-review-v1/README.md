# HTML Interactive Review v1 互动复习课件模板

## 定位

这是 English Coach 第一版互动复习课件模板，用 Day01「雨天开车去上班」课件固化而来。

## 已确认能力

| 模块 | 状态 |
|---|---|
| 顶部章节导航 | 已实现 |
| 学习进度 | 已实现，localStorage 保存 |
| 表达卡片已掌握 | 已实现，localStorage 保存 |
| 练习答案折叠 | 已实现 |
| 全部展开 / 全部收起 | 已实现 |
| 深色 / 浅色模式 | 已实现，localStorage 保存 |
| 返回顶部 | 已实现 |
| 打印 / 导出 PDF | 已实现 |
| 响应式布局 | 已实现 |
| 单文件运行 | 已实现 |

## 后续优化方向

| 方向 | 说明 |
|---|---|
| 视觉模板 | 可继续优化卡片密度、首页插画、词汇网络图 |
| 内容模板 | 可把每日课程输入转成固定 JSON 结构，再渲染为 HTML |
| 复习系统 | 可增加跨天复习队列和表达检索 |
| 发音训练 | 暂不做假播放按钮；后续接真实音频或 TTS 再加 |
