# HTML After-Class Review v2 课后复习模板

## 定位

v2 是 English Coach 后续唯一使用的每日复习材料模板。

它不再把“互动课件、日课材料、教学日记”分成多个文件，而是全部融合进一个可直接打开的 HTML。

## 目标用户

| 用户 | 使用场景 |
|---|---|
| 成人英语学习者 | 课后快速复习、反复跟读、回看重点表达 |
| English Coach | 长期追踪学生成长、沉淀下一步教学策略 |

## 页面结构

| 顺序 | 模块 | 默认状态 |
|---|---|---|
| 1 | Cover 封面 | 展开 |
| 2 | 3-Minute Review 快速复习 | 展开 |
| 3 | Story 真实场景回放 | 展开 |
| 4 | Original → Natural 表达升级 | 展开 |
| 5 | Key Expressions 核心表达 | 展开，可标记已掌握 |
| 6 | Deep Word 词汇深挖 | 展开 |
| 7 | Fixes 发音 / 语法 / 用词修正 | 展开 |
| 8 | Mini Practice 即时练习 | 答案折叠 |
| 9 | Speak It Yourself 开口挑战 | 参考答案折叠 |
| 10 | Growth Note 成长记录 | 压缩展示 |

## 交互能力

| 能力 | 要求 |
|---|---|
| 顶部章节导航 | 必须有 |
| 学习进度 | 基于核心表达已掌握数量 |
| 已掌握状态 | localStorage 保存 |
| 答案折叠 | details / summary |
| 全部展开 / 收起 | 必须有 |
| 深浅色模式 | localStorage 保存 |
| 返回顶部 | 必须有 |
| 打印 / PDF | 必须有打印样式 |

## 内容原则

| 原则 | 说明 |
|---|---|
| 复习优先 | 最常用、最该背的内容放前 30% |
| 少而准 | 不追求内容多，追求下次真能说出口 |
| 一个 Deep Word | 每节课最多深挖 1 个核心词 |
| 成长记录压缩 | 教学日记只保留观察、进步、下一步策略 |
| 忠于原课 | 不擅自扩展大量未学内容 |

## 文件规则

每天只生成：

```text
courseware-课件/YYYY-MM-DD-DayXX-topic-中文主题/index.html
```

默认不再生成独立 Markdown 日课材料和 Markdown 教学日记。
