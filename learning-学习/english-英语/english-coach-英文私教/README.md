# English Coach 英文私教

定位：用 Codex 管理英语私教学习闭环，用 ChatGPT 对话模式完成实时口语陪练。

核心方法：先表达，再纠正，再升级，再复习。

## 分工

| 模块 | 负责什么 | 产物 |
|---|---|---|
| ChatGPT 对话模式 | 实时开口、角色扮演、语音交流、即时纠错 | 对话记录、原句、修改句 |
| Codex | 日常计划、笔记归档、复习安排、弱项追踪、工作学习场景融合 | 日课笔记、复习库、进度表 |
| 现有英语日课 pipeline | 亲子英语音频和素材生产 | podcast、脚本、亲子表达 |

## 日常学习流程

| 阶段 | 时间 | 动作 | Codex 管理点 |
|---|---:|---|---|
| 预热 | 3 分钟 | 选今天真实场景，回顾旧句 | 从复习库抽 3-5 句 |
| 自由表达 | 10 分钟 | 在对话模式里连续说，不停下来改错 | 记录原句和卡壳点 |
| 表达升级 | 10 分钟 | 让 Coach 纠错、改成自然表达、补搭配 | 写入日课笔记 |
| 影子跟读 | 5 分钟 | 跟读升级后的 5-8 句 | 标注发音问题 |
| 巩固 | 2 分钟 | 定下明天要复习的句子 | 写入复习队列 |

## 场景池

| 场景类型 | 示例 | 用途 |
|---|---|---|
| 通勤与天气 | 开车上班、下雨、堵车、停车 | 高频日常表达 |
| 消费与社交 | 买咖啡、点餐、超市购物、闲聊 | 真实生活应对 |
| 亲子生活 | 吃饭、洗澡、穿衣、睡前、绘本 | 给孩子可复用 |
| 工作场景 | 会议、汇报、解释数据、推动项目 | 融入日常工作 |
| 旅行与公共服务 | 问路、酒店、机场、临时状况 | 低频但必要 |

## 每日复习材料规则

| 项目 | 规则 |
|---|---|
| 正式产物 | 每天只生成一个 HTML |
| 保存位置 | `courseware-课件/YYYY-MM-DD-DayXX-topic-中文主题/index.html` |
| 内容融合 | 互动课件 + 日课材料 + 教学日记 |
| 主要用途 | 课后复习 |
| 总目录 | 每节课只保留一个“打开复习材料”入口 |

## 每次练习后的输入格式

把 ChatGPT 对话模式里的内容发给 Codex 时，直接贴下面四项：

```text
日期：
场景：
我的原句 / 对话摘录：
Coach 给的修改和补充：
```

Codex 要输出并归档：

| 输出 | 内容 |
|---|---|
| 日课笔记 | 主题、原句、自然表达、词汇、发音、复习项 |
| 复习更新 | 新增表达、弱项、下次复习日期 |
| 明日建议 | 只给 1 个最适合的真实场景 |
